# 下一版本账户暂停与代理 UUID 管理需求

> 状态：需求规划，当前版本不实施代码或数据库变更  
> 日期：2026-07-05

## 1. 目标

下一版本完善账户暂停、付费恢复和代理 UUID 管理闭环：暂停用户后立即停止其代理能力，同时保留登录和续费入口；付费恢复后重新激活服务。允许 root 安全地自助重置自己的代理 UUID，但继续保护 root 不受其他管理员操作。

## 2. Root 自助重置代理 UUID

### 2.1 权限规则

- 仅允许 root 重置自己的 `users.proxy_uuid`。
- 其他管理员和操作员不得重置 root 的 `proxy_uuid`。
- root 仍禁止被其他账户暂停、删除或修改角色。
- 本功能不得修改账户主键 `users.uuid`。

### 2.2 重置行为

1. 生成新的 `proxy_uuid` 并保存。
2. 停止向节点同步旧 UUID。
3. 从所有已同步节点的配置中删除旧 UUID。
4. 应用节点配置并立即断开使用旧 UUID 的现有 VLESS 连接。
5. 将新 UUID 同步到目标节点。
6. 节点确认应用成功后，新 UUID 方可使用。

### 2.3 安全与审计

- 重置操作必须二次确认。
- 记录操作者、账户 UUID、旧代理 UUID、新代理 UUID、时间和节点同步结果。
- 非 root 操作 root 时继续返回 `root_protected`。
- 任一节点处理失败时必须展示失败节点和可重试状态，不得错误地报告全部成功。

## 3. 用户暂停

### 3.1 触发条件

- 管理员手动暂停。
- 账户欠费或订阅到期。
- 其他明确的风控或运营策略触发。

### 3.2 暂停后的用户体验

- 用户仍可登录控制台。
- 用户可以查看账户状态、暂停原因、欠费信息和续费入口。
- 除登录、退出、查看必要账户信息和续费外，所有业务功能暂停。
- 管理页面必须明确显示“已暂停”，不得因接口缺少状态字段而回退显示为“活跃”。

### 3.3 暂停后的代理行为

1. 将账户状态更新为暂停。
2. 停止向所有节点同步该用户的 `proxy_uuid`。
3. 从所有已同步节点配置中删除该 UUID。
4. 应用节点配置，立即断开该 UUID 已建立的 VLESS 连接。
5. 禁止该 UUID 建立新连接。
6. 保存每个节点的删除、应用和断连结果。

暂停不能只更新数据库状态；账户服务、配置同步、节点配置和运行中连接必须形成完整闭环。

## 4. 重新付费与激活

支付平台确认重新付费成功后：

1. 将账户进入恢复处理中状态。
2. 保留并重新使用原 `proxy_uuid`，默认不生成新 UUID。
3. 将该 UUID 重新同步到所有有效目标节点。
4. 等待节点配置应用成功。
5. 必要节点全部同步成功后，将账户恢复为激活状态并开放业务功能。
6. 若同步失败，保持代理能力关闭，展示失败原因并允许重试。

只有原 UUID 已被主动重置、吊销或发生安全风险时，恢复流程才生成新 UUID。

## 5. 建议状态模型

| 状态 | 登录与续费 | 业务功能 | 节点 UUID | VLESS 连接 |
| --- | --- | --- | --- | --- |
| `active` | 允许 | 允许 | 已同步 | 允许 |
| `suspended` | 允许 | 暂停 | 已删除 | 禁止 |
| `reactivating` | 允许 | 暂停 | 同步中 | 禁止 |
| `sync_failed` | 允许 | 暂停 | 不完整或失败 | 禁止 |
| `revoked` | 允许 | 按账户状态决定 | 旧 UUID 已删除 | 旧 UUID 永久禁止 |

## 6. 验收标准

- 暂停后，数据库和管理页面均显示正确的暂停状态。
- 暂停用户仍可登录、查看暂停原因并完成续费。
- 暂停用户无法使用其他业务功能。
- 暂停后所有目标节点均不再包含该用户 UUID。
- 暂停前已建立的 VLESS 连接被及时断开，旧连接不能继续传输。
- 暂停 UUID 无法建立新连接。
- 支付确认后自动启动恢复同步流程。
- 必要节点同步成功前不得提前恢复代理能力。
- 恢复成功后使用原 UUID，且可以正常建立新连接。
- root 可以重置自己的 `proxy_uuid`，但不能通过该操作修改 `users.uuid`。
- 其他管理员对 root 执行重置、暂停、删除或角色修改时均被拒绝。
- UUID 重置、暂停、节点删除、断连、恢复及同步结果均有审计记录。

## 7. 非本版本范围

- 当前版本不修改现有接口、数据库或节点配置。
- 不在本需求中改变账户主键 `users.uuid`。
- 不以删除用户账户代替暂停。
- 不要求暂停用户退出登录；登录能力用于查看状态和完成续费。
